# NhaWOW mobile - sửa ngày 2026-08-28

## Đã sửa trong source này

1. **Icon ứng dụng**
   - Thêm `flutter_launcher_icons: ^0.14.4` vào `dev_dependencies`.
   - Tạo `assets/icon/app_icon_square.png` và `assets/icon/app_icon_foreground.png`.
   - Thay trực tiếp icon Flutter mặc định trong toàn bộ `android/app/src/main/res/mipmap-*`.
   - Thay AppIcon iOS.
   - Đổi tên hiển thị app thành `NhaWOW` trên Android/iOS.

2. **Chọn ngôn ngữ**
   - Logic lần đầu vẫn giữ đúng: chỉ hiện khi thiết bị chưa có `nhawow.language` trong SharedPreferences.
   - Khi test APK mới trên máy đã từng cài app, Android vẫn giữ dữ liệu nếu cài đè. Muốn kiểm tra màn chọn ngôn ngữ lần đầu, hãy gỡ app cũ hoặc Clear storage trước khi cài.

3. **Xin quyền thông báo**
   - Thêm `flutter_local_notifications`.
   - Popup xin quyền notification được gọi ngay sau khi người dùng chọn ngôn ngữ.
   - Với người dùng đã có lựa chọn ngôn ngữ từ bản cũ, app cũng kiểm tra/xin quyền khi khởi động bản cập nhật.
   - Không còn phụ thuộc việc phải đăng nhập rồi mới xin quyền.

4. **Tin nhắn / push khi app đang mở**
   - Khi FCM tới foreground, app tạo notification hệ thống (banner/sound/vibration) thay vì chỉ refresh chat.
   - Tap notification có thể chuyển lại vào luồng mở Chat / Property / Notifications dựa trên payload.

5. **Android Gradle**
   - Bật core library desugaring và multidex theo yêu cầu của `flutter_local_notifications`.

## Việc bạn vẫn phải cấu hình bằng thông tin thật

Source không có Firebase credential thật. Hãy copy:

`firebase_config.example.json` -> `firebase_config.json`

và điền các giá trị từ Firebase Console.

Build APK nên dùng:

```powershell
.\build_android_release.ps1
```

hoặc chạy thủ công:

```bash
flutter clean
flutter pub get
dart run flutter_launcher_icons
flutter build apk --release --dart-define-from-file=firebase_config.json
```

Nếu chỉ chạy `flutter build apk --release` mà không truyền `firebase_config.json`, app vẫn mở và vẫn có thể xin quyền notification, nhưng **FCM push thực tế sẽ không hoạt động**.

## Backend để tin nhắn thật sự về điện thoại

Backend NhaWOW cần có:

- `POST /mobile-api/push/register`
- `POST /mobile-api/push/unregister`
- Sau khi gửi chat thành công, backend gửi FCM tới token người nhận.

Khuyến nghị FCM payload:

```json
{
  "notification": {
    "title": "NhaWOW",
    "body": "Bạn có tin nhắn mới"
  },
  "data": {
    "type": "chat",
    "conversationId": "123"
  }
}
```

Nếu backend chưa gửi FCM thì sửa mobile thôi chưa thể tạo ra push từ server.
